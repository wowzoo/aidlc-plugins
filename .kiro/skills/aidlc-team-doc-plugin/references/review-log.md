# 검토 기록 형식

**위치:** 검토 기록은 plugin 폴더 밖, 인계하지 않는 곳에 둡니다(예: `<SRC>/../.review-artifacts/<문서>-review.md`).
다음 사람이 이 파일만 읽고 이어서 할 수 있어야 합니다.

```markdown
# <문서> plugin stage 검토 기록

- 대상: <파일 목록>
- 검토자: plugin-doc-reviewer (<model>)
- 1차 출처: <PROJECT>/<LEAF>/  (AI-DLC <버전>)

## dry run N차 — 애매한 곳 <수>건

| 보고 | 처리(템플릿 / stage) |
|---|---|

## 검토 N차 — <A|B|C>

판정 근거: <한 문장>

| 지적 | 확인 결과(맞음 / 틀림 / 부분적으로 맞음)와 근거 파일:줄 | 처리 |
|---|---|---|

**검증:** <5단계 결과, 실행해 본 명령 블록>

## 되돌리지 말 결정

- <결정 — 이유>

## 반영하지 않은 지적

- <지적 — 틀렸던 근거 — 검토자의 재판정 결과>

## 검증하지 않은 것

- <예: 실제 intent 실행>
```
